# drafts/

Working markdown drafts. Two rules of this folder:

1. Everything here is AI-generated (Claude, under the WSG skill). Human-authored work never starts in this folder.
2. Git keeps only the latest surviving version of each article. Superseded versions (v1..n-1) stay in the local working folder archive, not in the repository.

Naming: `draft-{slug}-v{n}.md`. Revisions bump the version; do not overwrite a prior version in place.
