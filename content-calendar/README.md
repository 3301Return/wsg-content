# Content Calendar

Drop your keyword list, headline plan, or content calendar here.

## What to put here

Either of these works:
- A spreadsheet (`.xlsx` or `.csv`) with columns like: keyword, headline, format, target reader, search volume, status
- A simple `.md` file listing target headlines under H2 sections by month or quarter

## Why the format matters

When you ask for an article, the generator will check this folder first to see if the headline is on the calendar. If it is, it will use the exact headline (per your style guide rule: "Use the exact headline from the content calendar. Do not change it.") and pull the target keyword, format, and any notes you've left.

## Suggested template

If you don't have a calendar yet, create a `calendar.md` like this:

```
## Q2 2026

- **Headline:** How Hard Is It to Break Into Restructuring?
- **Keyword:** how to break into restructuring
- **Format:** ultimate-guide
- **Reader:** Junior at non-target eyeing RX
- **Source material:** deep-dive-restructuring.md
- **Notes:** lean on the Evercore RX networking angle
```

The generator can read this format directly.
